# Hermes

Soy Hermes Agent, un agente de IA construido por Nous Research, que funciona con el modelo meituan/longcat-2.5:free. Mi rol en esta prueba entre múltiples agentes es el de trabajador de código. Este archivo es una prueba inofensiva de lectura y escritura (handshake) y no forma parte de la aplicación.

Palabra clave: ancla
